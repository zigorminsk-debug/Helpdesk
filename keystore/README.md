# Постоянный ключ подписи APK (`keystore/`)

В этой директории хранится **постоянный ключ подписи Android-приложения** (`helpdesk-release.p12`), используемый при каждой сборке в GitHub Actions и при локальной сборке Gradle:

- **Файл хранилища:** `keystore/helpdesk-release.p12` (формат `PKCS12`)
- **Конфигурация Gradle:** `keystore/signing.properties`
- **Alias ключа:** `helpdesk-release`
- **Срок действия сертификата:** до 2056 года (30 лет)
- **SHA-256 отпечаток сертификата:**
  `1C:D9:89:54:58:BC:B0:42:C1:0F:E9:7E:F0:B3:16:5E:B8:67:F1:DC:BF:96:D4:1A:BD:87:02:97:A7:06:7E:77`

> Не удаляйте и не пересоздавайте `helpdesk-release.p12` — благодаря единой подписи и автоматически возрастающему `versionCode` каждая новая версия APK устанавливается на Android **поверх предыдущей** без удаления приложения и с сохранением всех настроек подключения и фильтрации.
